# Можно Лучше — лендинг

Одностраничный продуктовый лендинг для «Можно Лучше» — велнес-сервиса с ИИ-наставником
и геймификацией здоровых привычек (прототип TRL-4, проект остановлен в 2024 году).

Сделан как демонстрационная работа: показать умение собрать современный D2C-фронтенд,
понимание структуры воронки телемедицинского лендинга и аккуратность в вёрстке
и адаптиве. Сервис не является медицинским и не даёт медицинских рекомендаций.

## Стек

- Next.js 15 (App Router, TypeScript strict), статический экспорт
- Tailwind CSS, все цвета — через дизайн-токены, без UI-китов
- next/font (Manrope, кириллический сабсет), next/image
- Framer Motion — только лёгкие появления при скролле, с учётом prefers-reduced-motion

## Сколько заняло

Около четырёх часов: каркас и токены, секции, квиз, полировка адаптива и доступности.

## Что осознанно не делали и почему

- **Бэкенд, формы, аналитику** — квиз работает на useState и таблице соответствий,
  ничего никуда не отправляется: для демо честнее показать механику, чем имитировать сервис.
- **Обещания результата в цифрах и медицинские формулировки** — тексты держатся
  в рамке поддержки привычек, каждую формулировку можно показать врачу.
- **Тяжёлую анимацию и счётчики цифр** — спокойный премиальный тон важнее эффектов.
- **Фото команды** — вместо низкокачественных фото из презентации — инициалы
  в фирменном круге.
